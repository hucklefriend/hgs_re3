# HGN connection-terminal mock

A static, Laravel-independent variation of the HGN redesign mock.

- `index.html`: title screen and latest transmissions
- `lineup.html`: database menu
- `game.html`: game detail
- `styles.css`: connection terminals, node port, and responsive styles
- `app.js`: node handoff animation and local interactions

No Ajax APIs are used. Preview from `/new_design2/` when the local server is running.
The original `/new_desgin/` mock remains unchanged.
